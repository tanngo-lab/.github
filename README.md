# tanngo-lab/.github

This repo powers the [github.com/tanngo-lab](https://github.com/tanngo-lab) org landing page.

The rendered profile lives at `profile/README.md`. Animated SVG assets are in `assets/`. Everything is hand-authored, self-contained SVG (no build step, no external fonts) so animations play through GitHub's image proxy.

If you want to see the page itself, visit [github.com/tanngo-lab](https://github.com/tanngo-lab).
