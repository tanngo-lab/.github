# tanngo-lab/.github

This repo powers the [github.com/tanngo-lab](https://github.com/tanngo-lab) org landing page.

The rendered profile lives at `profile/README.md`. The hero animation is at `assets/hero.svg` — a single hand-authored, mode-aware SVG. No build step, no external fonts, no JavaScript, so animations play through GitHub's image proxy.

If you want to see the page itself, visit [github.com/tanngo-lab](https://github.com/tanngo-lab).
